# 2026_Sablefish_CIE
Repository for Models and Sims Associated with the 2026 Alaskan Sablefish CIE Review.

The 'Documents for Review' folder includes the final assessment model documents that are the basis of the CIE review.

The 'Model Runs' folder contains the final model runs and associated R files produced to run and as output by the SPoRC package as implemented for the sablefish assessment.

The 'Sablefish Background Documents' contains documents pertinent to sablefish, which may help understand assessment modeling decisions and parametrization, but are NOT part of the CIE review.
